数据源与可靠性说明

局限与免责： ① 各国统计口径与数据年份不一致（多为 2024–2025 年最新可得值），跨国比较存在时滞差异； ② VIX 衡量的是美股市场对未来 30 天波动率的预期，不等于全球经济本身的风险； ③ EPI / MFI / GFI 为本模型构建的综合指数，属于研究性指标，非官方发布指数，不构成任何投资建议； ④ 世界银行部分指标对最不发达国家存在缺失，样本已通过“人口 ≥ 100 万”过滤，未覆盖微型经济体。

数据来源：World Bank Open Data API · IMF DataMapper API · CBOE VIX 官方历史数据。指数模型与可视化为本页自建。
