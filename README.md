# 全球经济繁荣与恐慌指数仪表盘

> Global Economic Prosperity & Fear Index Dashboard

用**世界银行、IMF、CBOE 官方公开数据**构建的单一页面仪表盘，把"经济好不好"和"市场怕不怕"两个问题量化成三个可横向比较的指数，覆盖**经济体量前 50 名的国家或地区**。

所有数字都可回溯到官方 API，没有人工估算值。

---

## 三个指数

| 指数 | 含义 | 构成 |
|---|---|---|
| **EPI** 经济繁荣指数 | 越高越好，衡量经济体的综合繁荣水平 | 富裕水平 28% + 人力资本 16% + 增长动能 16% + 就业质量 12% + 物价稳定 12% + 外部韧性 10% + 人口活力 6% |
| **MFI** 宏观恐慌指数 | 越高越危险，衡量宏观基本面的压力 | 通胀压力 22% + 增长失速 20% + 就业压力 16% + 债务压力 14% + 外部脆弱 14% + 宏观波动 14% |
| **GFI** 综合恐慌指数 | 市场情绪 + 宏观压力的合成体温计 | `0.6 × VIX 历史分位 + 0.4 × 全球 MFI（GDP 加权）` |

### 归一化方法

- 每个指标在**样本内**做 `5%–95% 缩尾 min-max 归一化`，映射到 0–100 分，剔除离群值干扰
- 人均 GDP 先取 `log10` 再归一化（收入边际效用递减）
- 负向指标（失业率、通胀偏离、波动率等）取 `100 − 得分`
- **缺失值不记零分**：某维度数据缺失时，其权重按比例重分配给其余维度，避免"数据缺失"被误读为"表现极差"

## 样本口径

按**经济体量（GDP 现价美元，最新可得年份）**对全部经济体排名，取**前 50 名**进入样本。

- 前 50 大经济体合计约 **109.8 万亿美元，占全球 GDP 的 92.8%**
- 人口合计约 **63.2 亿，占全球 77.0%**
- 门槛：第 50 名为尼日利亚（约 2,910 亿美元）

选这个口径有两个考虑：一是覆盖九成以上全球经济总量，横向可比性强；二是抓取效率高——先按 GDP 定榜，再只对入选经济体定向抓取其余 18 项指标，请求体量降到全量抓取的 1/5。

页面提供三档视图切换：**G20**（19 个主权成员国）/ **主要经济体**（G20 + 区域代表）/ **全部样本**（前 50 名）。

## 数据源

| 来源 | 内容 | 说明 |
|---|---|---|
| [World Bank Open Data](https://data.worldbank.org/) | 19 项指标（GDP、人口、通胀、失业、预期寿命、人力资本、外储、债务、互联网普及率等） | 官方开放 API，无需密钥 |
| [IMF WEO / SDMX](https://data.imf.org/) | 一般政府总债务/GDP（`GGXWDG_NGDP`） | 补充世行该项覆盖率不足；**必须截断未来预测值** |
| [CBOE VIX](https://www.cboe.com/tradable_products/vix/) | VIX 官方日频历史（1990 年至今） | 官方 CSV |

### 两个数据陷阱（已处理）

1. **IMF 数据含未来预测值**（至 2031 年）。不截断会把预测值当实际值，日本的债务率就会从 204.8% 变成 192.8% 之类的错值。代码里用 `cap = min(2025, 当前年)` 截断。
2. **IMF 旧 DataMapper `api/v1` 接口已下线**（返回 `{"error":"Blob not found"}`）。本项目已迁移到 `api.imf.org/external/sdmx/2.1`，并加了本地缓存兜底：接口异常时回落到上次成功抓取的数据，避免债务维度集体缺失导致 MFI 悄悄失真。

## 快速开始

### 直接打开

双击 `index.html` 即可，无需构建、无依赖、无 npm install。

> 注意：用 `file://` 打开时浏览器的 CORS 限制不影响本页，因为数据以 `data/data.js`（挂载 `window.__GLOBAL_DATA__`）形式加载，而不是 `fetch()` JSON。

### 或用本地服务

```bash
python -m http.server 8000
# 访问 http://127.0.0.1:8000/index.html
```

### 刷新数据

```bash
python fetch_data.py
```

约 1 分钟，会重新抓取全部数据并覆盖 `data/data.js` 与 `data/global_data.json`。页面无需改动。

依赖：Python 3.8+，**仅标准库**（`urllib` / `csv` / `json`），不需要 pip 安装任何包。

### 冒烟测试

```bash
node smoke_test.js
```

用最小 DOM 桩执行 `app.js` 的全部渲染路径，覆盖 19 个渲染区块、三档视图切换、样本口径一致性（数量=50、GDP 排名 1..50 无重复且递减、G20 无缺失），全部通过才会退出码 0。

## 关于地图密钥

地图模块用**腾讯地图 GL JS**（合规地图服务商，国界与领土表达以底图为准，本项目只叠加数据气泡、不自行绘制行政边界）。

**腾讯地图密钥不能公共共享**——key 与账号绑定，且有配额和安全策略（域名白名单等），共用会消耗他人额度。但**个人开发者可以免费申请**：

1. 打开 https://lbs.qq.com ，用微信/QQ/手机号注册并完成实名认证
2. 控制台 → 应用管理 → 我的应用 → 创建应用 → 添加 Key
3. 复制 key，粘到页面底部输入框，点「保存并重载地图」（只存在你自己的浏览器 localStorage）

个人开发者免费额度为**日调用量 10,000 次、并发 5 次/秒**，个人浏览足够。按腾讯条款，个人额度仅限个人学习与非商业用途，企业使用需商业授权。

**没有密钥也能用**：地图加载失败时页面会自动切换为「**分组气泡视图**」——按地区分组，气泡面积代表规模、颜色代表指数，数据与地图模式完全一致，只是不带地理底图。这个降级视图是纯 CSS 布局，不涉及任何经纬度或国界渲染。

## 项目结构

```
global-economy-dashboard/
├── index.html            # 页面骨架（语义化 section，无内联逻辑）
├── assets/
│   ├── app.js            # 全部渲染逻辑（原生 JS，无框架）
│   └── style.css         # 设计令牌 + 响应式 + 动画
├── data/
│   ├── data.js           # 数据快照（window.__GLOBAL_DATA__，供 file:// 直接打开）
│   ├── global_data.json  # 同一份数据的 JSON 版本
│   └── imf_debt_cache.json  # IMF 抓取失败时的兜底缓存
├── fetch_data.py         # 抓取 + 指数计算（仅标准库）
├── patch_geo.py          # 增量补经纬度（避免重跑全量抓取）
└── smoke_test.js         # DOM 桩冒烟测试
```

## 主要功能

- **世界地图**：气泡大小代表人口或 GDP，颜色代表 EPI / MFI / 增速，点击联动国家详情
- **三档视图**：G20 / 主要经济体 / 全部样本，KPI、排行、表格、散点、地图同步切换
- **恐慌仪表盘**：VIX 量表 + 近一年走势 + 历史极值日 + GFI 拆解（VIX 分位 vs 宏观压力各占多少）
- **完整数据表**：12 列指标，支持排序、按地区/收入组筛选、关键词搜索、CSV 导出
- **国家详情**：18 项指标卡 + EPI/MFI 各维度得分拆解 + 实际权重构成
- **实时校验**：可选调用世界银行 API 抽查当前国家的指标，与快照比对
- **动画**：数字滚动、条形错峰增长、折线描绘、气泡渐次出现，全部尊重 `prefers-reduced-motion`

## 局限与免责

1. 各国统计口径与数据年份不一致（多为 2024–2025 年最新可得值），跨国比较存在时滞差异
2. VIX 衡量的是**美股市场对未来 30 天**波动率的预期，不等于全球经济本身的风险
3. EPI / MFI / GFI 为**研究性自建指数**，非官方发布指数，**不构成任何投资建议**
4. EPI / MFI 依赖年度指标，月度刷新时通常只有 VIX 与 GFI 会变化；若需日频敏感度，应接入高频市场指标（10Y 美债收益率、美元指数、高收益债信用利差等）
